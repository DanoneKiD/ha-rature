# Rature

Client mobile des listes de tâches (`todo.*`) de Home Assistant. Présentation et commandes : `README.md`.

- Interface dans `web/` (Vite, JavaScript sans framework), coquille Flutter dans `app/`.
- Avant chaque build Flutter : `npm run app`. Tests : `npm test`.
- Textes affichés : tout passe par `t()` (`web/src/core/i18n.js`), en français, anglais et allemand.
- Ce dépôt est public : ni secret, ni chemin local, ni nom réel, ni identifiant de compte.
- Notes privées : `CLAUDE.local.md`, ignoré par git.
